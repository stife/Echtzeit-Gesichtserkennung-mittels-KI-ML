Echtzeit-Gesichtserkennung mit KI/ML

📌 Übersicht

Dieses Projekt demonstriert ein Echtzeit-Gesichtserkennungssystem mit KI/ML. Es erfasst Live-Videos, erkennt Gesichter und identifiziert Identitäten mithilfe eines TensorFlow-basierten Modells auf Basis der VGG16-Architektur.

🎯 Funktionen

- Echtzeit-Bildaufnahme mit OpenCV.

- Gesichtserkennung und -identifizierung mittels Deep Learning.

- Modell optimiert für schnelle Inferenz mit GPU-Unterstützung.

- Modulares Design für Training und Test.

🛠️ Technologie-Stack

- Programmiersprache: Python

- Frameworks/Bibliotheken: TensorFlow, OpenCV, NumPy, Matplotlib
- Modellarchitektur: VGG16

🚀 Installation und Verwendung

Voraussetzungen
- Python 3.8 oder höher
- Erforderliche Bibliotheken: TensorFlow, OpenCV und Matplotlib

Schritte zum Ausführen
1. Klonen Sie das Repository und wechseln Sie in das Projektverzeichnis.

 2. Bilder aufnehmen, Modell trainieren und Echtzeiterkennung durchführen.

📂 Projektstruktur

Das Projekt umfasst Verzeichnisse zur Datenspeicherung, Skripte zur Datenerfassung und zum Modelltraining sowie gespeicherte Modelle für Erkennungsaufgaben.

📖 Funktionsweise

1. Datenerfassung: Bilder werden per Webcam aufgenommen und für das Training gespeichert.

2. Modelltraining: Ein Gesichtserkennungsmodell wird mithilfe von VGG16 zur Merkmalsextraktion trainiert.

3. Echtzeiterkennung: Gesichter werden im Live-Webcam-Feed identifiziert und mit bekannten Identitäten abgeglichen.

📚 Zukünftige Verbesserungen

- Unterstützung für größere Datensätze hinzufügen.

- Fortschrittlichere Gesichtserkennungsalgorithmen implementieren (z. B. FaceNet).

- Genauigkeit bei unterschiedlichen Lichtverhältnissen und Blickwinkeln verbessern.
